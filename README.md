# CSC649 Python Experiment

## Description of the program

This program accepts a sentences from the user and display the number of words and characters in the sentences.

The program also handles empty input by displaying a suitable message such as "You did not enter a sentence".

# How to run this program

1. Open the project in PyCharm.
2. Make sure the Python interpreter is Python 3.12.
3. Open 'main.py'.
4. Click the Run button to run the proram.
5. Enter a sentence when prompted.

## The Test Results

### Test 1: Normal sentence

Input:
I cooked pasta today

Result:
Word count: 4
Character count (including spaces): 20

### Test 2: Empty input

Input:
No input.

Result:
You did  not enter a sentence.

### Test 3: Multiple space

Input:
I cooked   pasta  today

Result:
Word count: 4
Character count (including spaces): 24

## Limitation

The program only accepts text input from the command line and does not save the user's results after the program ends.
